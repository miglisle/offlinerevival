#Offline Revival

Local launcher and hosting tools for the classic Roblox client versions included in this project. The launcher includes avatar customization, local services, maps, and the original client integrations.

To start, open OfflineRevival.exe from the project folder. Use the Services tab to start or stop local services. The launcher includes click sounds; mute Offline Revival in the Windows Volume Mixer if desired.
